What is PRSense?

A deterministic, diff-first pull request review engine that surfaces high-confidence signals from code changes — without hallucinations, noise, or automated modifications.

$ npm i -g @prsense/cli && prsense review . click to copy

Why PRSense exists

Other tools

  • Comment on code that didn't change
  • Hallucinate files, symbols, or context
  • Generate verbose, low-signal feedback

PRSense

  • Diff-first — only analyzes what changed
  • Deterministic — reproducible and inspectable
  • Signal-based — concise, high-confidence findings

How PRSense works

PRSense processes pull requests through a structured pipeline:

  • Ingests the git diff and metadata
  • Builds contextual understanding from the repository
  • Runs analysis using LLMs (local or cloud)
  • Emits structured review signals grounded in actual changes

Each signal can be traced back to specific lines in the diff — nothing is fabricated.

Key characteristics

Deterministic

Results are consistent and explainable. Same input, same output.

Diff-first

No irrelevant analysis outside the change set. Only what matters.

Human-in-the-loop

No autonomous code changes. Engineers stay in control of every decision.

Self-hosted

Run locally or within your own infrastructure. No code leaves your machine.

LLM-agnostic

Supports both local and cloud models. Plug in whichever LLM fits your workflow and privacy requirements.

Where PRSense fits

PRSense is not a general-purpose repository memory system or autonomous coding agent.

It is a focused review engine designed to assist engineers in understanding risk, correctness, and impact within pull requests.

Getting started

Install the CLI and review your first pull request in seconds:

$ npm i -g @prsense/cli click to copy

You can also run PRSense in CI or as a long-lived daemon for automated workflows.

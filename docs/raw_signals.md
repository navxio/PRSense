[HIGH] spring-core/src/main/java/org/springframework/core/io/buffer/JettyDataBuffer.java release() now always delegates to chunk.release(), so releasing a sliced/split buffer can free the shared Jetty chunk while other JettyDataBuffer instances still have a positive local ref count. ↳ The previous implementation tracked a per-buffer refCount and only returned result==0 for non-chunk buffers, while chunk-backed buffers coordinated local state with chunk retention.
